# Visual HTML Editor

## Запуск

Скачайте index.html. На ПК откройте файл двойным щелчком в современном браузере. Интернет, сервер и установка пакетов не нужны. Внутри есть демо; отдельный demo.html можно загрузить через «Загрузить HTML».

На Android сохраните index.html в «Загрузки», затем выберите «Открыть с помощью» → браузер. Нужен именно браузер с JavaScript, а не просмотрщик HTML файлов. Доступность открытия локального HTML зависит от файлового менеджера и браузера. На iOS приложение «Файлы» может открыть Quick Look без выполнения JavaScript: такой просмотр не поддерживается; нужен браузер/приложение, разрешающее выполнение локальных HTML. Универсальный запуск из «Файлов» iOS без дополнительных средств не гарантируется.

## Работа

1. Загрузите самостоятельный .html/.htm со встроенным CSS.
2. Выберите элемент в предпросмотре или DOM. На телефоне DOM открывается отдельной кнопкой.
3. Разверните нижнюю панель нажатием на её верхнюю кнопку: свёрнута → половина → полностью → свёрнута.
4. Измените значения CSS, завершив ввод Enter или выходом из поля. Пустое значение удаляет вашу правку.
5. Для размеров потяните правый, нижний или угловой синий маркер. Масштаб учитывается. Один жест — один шаг истории.
6. Используйте ↶/↷, сравнение «Оригинал», скрытие рамок и экспорт ТЗ. Если копирование недоступно, текст выделяется для ручного копирования.
7. «Скачать HTML» сохраняет документ с правками; служебный код редактора в него не добавляется.

## Изоляция

Предпросмотр использует srcdoc, sandbox="allow-scripts" **без allow-same-origin**. Выполняется только встроенный мост редактора с новым случайным CSP nonce. Скрипты документа, обработчики событий, вложенные документы, SVG/MathML, навигационные атрибуты и внешние подключения удалены из копии предпросмотра. CSP блокирует сеть, формы и любые другие скрипты. Сообщения проверяются по окну отправителя и случайному токену. Основной документ не открывает доступ к своим API.

Оригинал хранится отдельно. Экспорт HTML сохраняет оригинальные скрипты и атрибуты исходного файла: это редактированный исходник, а не обезвреженная копия. При самостоятельном открытии экспортированного файла его исходные скрипты могут выполняться.

## Ограничения MVP

- История только в памяти: закрытие/перезагрузка редактора теряет несохранённые правки.
- Внешние изображения, CSS, шрифты и JavaScript не загружаются даже при наличии интернета. Поддерживаются встроенный CSS и растровые data:image;base64 изображения. SVG и вложенные документы в предпросмотре отключены.
- Вычисленные исходные значения фиксируются при загрузке HTML; их исходная ширина viewport указана в ТЗ. После смены viewport они не пересчитываются. Для нового исходного замера загрузите исходник при нужной ширине.
- Отдельные вкладки Flex/Grid отсутствуют: базовые свойства доступны в «Позиция». Перемещение выполняется через position/top/left/margin, не свободным перетаскиванием блока.
- HTML парсится и сериализуется DOMParser: форматирование, регистр атрибутов и некорректная разметка могут нормализоваться. Это не побайтовое сохранение.
- Для точного применения в предпросмотре/экспорте правки получают inline !important. ТЗ рекомендует агенту адаптировать их к архитектуре CSS проекта.
- Размеры с ограничениями min/max, flex/grid, transform, aspect-ratio могут не совпадать с движением маркера. Для сложных transform используйте числовые поля. Маркеры управляют CSS width/height; единицы при жесте становятся px, числовые правки сохраняют введённые единицы.
- Ширина viewport меняется; высота области подстраивается под содержимое до 50 000px, поэтому vh и position:fixed не воспроизводят физический экран телефона. Очень большие документы могут работать медленно.
- ТЗ различает inline и вычисленные значения, но не определяет конкретный исходный CSS-файл/правило. Селекторы с nth-of-type помечаются как зависимые от DOM. Текст не гарантирует пиксель-в-пиксель результат.

## Проверка в этой среде

Проверка синтаксиса JavaScript через node --check прошла. Подготовлен сценарий браузерных проверок test.cjs, но запуск Chromium заблокирован ограничением среды: socket() failed: Operation not permitted. Поэтому реальные проверки File API, жестов, Clipboard, скачивания, мобильного браузера и защиты в браузере здесь не подтверждены. На реальных Android/iOS устройствах приложение не проверялось.
